패밀리타임 개인정보처리방침

시행일: 2026년 10월 10일

패밀리타임(이하 "앱")은 사용자의 개인정보를 소중히 다룹니다. 본 방침은 앱이 어떤 정보를 다루고 어떻게 보호하는지 설명합니다.

1. 수집하는 정보

앱은 개발자 서버를 운영하지 않으며, 사용자가 입력한 정보를 개발자에게 전송하지 않습니다.

  • 가족 목록과 일정(이름, 색, 이모지, 일정 제목, 시간, 메모, 알림 설정): 사용자의 기기 안에만 저장됩니다.
  • 구글 계정 정보(이름, 이메일, 프로필 사진): 사용자가 선택적으로 구글 로그인을 했을 때만, 앱 화면에 로그인 상태를 표시하기 위해 기기 안에서만 사용합니다.

2. 구글 드라이브 동기화

사용자가 구글 로그인을 하면 가족 목록과 일정이 사용자 본인의 구글 드라이브 앱 전용 공간(appDataFolder)에 백업되어 같은 계정의 다른 기기와 동기화됩니다. 이 공간은 사용자 본인과 앱만 접근할 수 있으며, 개발자를 포함한 제3자는 접근할 수 없습니다. 앱이 요청하는 구글 권한은 drive.appdata 하나이며, 사용자의 다른 드라이브 파일에는 접근하지 않습니다.

로그인하지 않으면 사용자가 입력한 데이터는 기기 밖으로 나가지 않습니다.

3. 광고

앱은 무료로 제공하기 위해 구글 애드몹(Google AdMob)의 배너 광고를 표시합니다. 애드몹은 광고를 보여주기 위해 기기의 광고 ID, 대략적인 위치(IP 기반), 기기 정보 등을 수집할 수 있습니다. 자세한 내용은 구글의 개인정보처리방침과 광고 설정을 참고하세요. 기기 설정에서 광고 ID 재설정이나 맞춤 광고 끄기를 할 수 있습니다.

앱 안에서 "광고 제거"를 구매하면 광고가 표시되지 않으며, 애드몹에 어떤 정보도 보내지 않습니다.

4. 인앱 결제

"광고 제거" 결제는 구글 플레이 결제 시스템으로 처리됩니다. 결제 정보(카드 번호 등)는 구글이 처리하며 앱과 개발자는 접근할 수 없습니다. 앱은 구매 여부만 기기에 저장합니다.

5. 기기 권한

  • 알림 / 정확한 알람: 사용자가 일정에 설정한 시간에 알림을 보내기 위해 사용합니다.
  • 인터넷: 구글 드라이브 동기화, 광고 표시, 인앱 결제에 사용합니다.

6. 정보의 삭제

  • 앱에서 가족이나 일정을 삭제하면 기기에서 지워지고, 동기화 중이면 드라이브의 백업도 함께 삭제됩니다.
  • 앱을 삭제하면 기기의 모든 데이터가 삭제됩니다.
  • 드라이브 백업은 구글 계정 설정 → 보안 → 타사 앱 및 서비스에서 "패밀리타임"의 접근 권한을 삭제하면 함께 삭제할 수 있습니다.

7. 제3자 제공

앱은 사용자가 입력한 정보를 제3자에게 제공하거나 판매하지 않습니다. 광고 표시를 위해 구글 애드몹이 위 3항의 정보를 처리하는 것 외에 분석 도구는 사용하지 않습니다.

8. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

9. 방침의 변경

본 방침이 바뀌면 앱 업데이트 안내 또는 이 페이지를 통해 알립니다.
